# Igra
Особенности приложения: • 3 уровня сложности («Слабый», «Средний», «Сложный») — подойдёт и детям, и взрослым. • Подсказки на сложных этапах и голосовая озвучка похвалы. • Подробная личная статистика пройденных уровней и серий побед. • Работает даже без интернета (кроме онлайн-режима «Морского боя»).
